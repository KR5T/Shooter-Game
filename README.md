# DEADLINE: MIDNIGHT

A dark deco atmospheric shooter experience built with Unity.

## About

DEADLINE: MIDNIGHT is a stylized action shooter focused on atmosphere, fast combat, and cinematic presentation.

I inspired from 2D game named Hotline Miami and I convert the gameplay of that to 3D game. I built up a dark deco atmosphere for that. 

## Built With

- Unity
- Blender
- C#
